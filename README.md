# FAS TechAssist Synergy – Homepage

Einseitige Homepage für **FAS TechAssist Synergy** (Marcel Kesek): Wartung & Protokolle nach DIN 14675 / VDE 0833, Dokumentation & Revision, Projektierung & Software, technischer Support.

Reines HTML/CSS/JS, kein Build-Schritt. Schrift Montserrat ist selbst gehostet (`fonts/`, SIL OFL).

## Lokal ansehen

```bash
python serve.py 8813
```

Dann <http://localhost:8813> öffnen.
